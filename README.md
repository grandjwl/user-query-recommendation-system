## 프로젝트 개요

- 단순 조건 기반 필터링을 넘어, 사용자 자연어 입력을 활용한 스킨케어 추천 시스템을 구현했습니다.  

- 예를 들어 *"갑자기 여드름이 났을 때 진정에 도움이 되는 크림"*과 같은 문장을 입력하면, 해당 상황에 맞는 제품을 추천하는 구조입니다.  

- 기존 키워드 매칭 방식의 한계를 보완하기 위해 의미 기반 유사도 계산 방식을 적용했으며, 필터링과 추천을 결합한 형태로 설계했습니다.

## 데이터 크롤링

- 올리브영 스킨케어 카테고리(스킨/토너, 크림, 로션, 에센스/세럼/앰플)를 대상으로 데이터를 수집했습니다.  

- 카테고리별 인기순 기준 24개씩 8페이지를 크롤링하여 총 192개의 제품 데이터를 확보했습니다.  

- 리뷰는 체험단을 제외하고 ‘도움순’ 상위 기준으로 수집했으며, 실제 사용자 의견이 반영되도록 구성했습니다.

![image](https://github.com/user-attachments/assets/0fd1d166-c6f4-493b-a9f8-552a08a2e5c3)

## 데이터 전처리

- 수집된 데이터를 통합한 뒤, 결측치 및 비정상 데이터를 정제했습니다.  

- 가격 대비 혜택을 반영하기 위해 ‘할인율’ 파생 변수를 추가했습니다.  

- 가격, 리뷰 수 등의 수치 데이터는 텍스트와 함께 활용할 수 있도록 문자열 형태로 변환하여 임베딩에 포함했습니다.

---

## 데이터 임베딩

- `SentenceTransformer`를 활용해 제품명과 리뷰 데이터를 벡터로 변환했습니다.  

- 단순 키워드 일치가 아닌 문장 의미를 반영하기 위해 선택한 방식이며, 의미 기반 유사도 계산이 가능하도록 구성했습니다.

---

## 데이터 필터링

- 사용자에게 간단한 질문을 제시하고, 가격이나 리뷰 수 등의 조건을 기준으로 1차 필터링을 수행했습니다.  

- 필터링은 선택적으로 적용할 수 있도록 설계하여 사용자 탐색 자유도를 유지했습니다.  

- 조건이 적용된 경우, 설정된 기준에 따라 상위 약 50% 데이터를 후보군으로 사용합니다.

---

## 추천 시스템

- 사용자 쿼리와 제품 간 유사도를 코사인 유사도 기반으로 계산했습니다.  

- 벡터 간 방향성을 활용한 방식으로, 텍스트 임베딩과의 적합성을 고려한 선택입니다.  

- 리뷰 데이터에는 지수 가중치를 적용하여 신뢰도 높은 정보가 더 크게 반영되도록 했습니다.  

- 최종 점수는 다음 기준으로 산정됩니다.  
  - 주요 요소: 리뷰, 제품명  
  - 보조 요소: 가격, 할인율, 리뷰 수  

- 필터링과 의미 기반 추천을 결합한 구조로, 사용자 조건과 맥락을 함께 반영할 수 있도록 구성했습니다.  

- 추천 결과에는 제품 정보와 함께 대표 리뷰를 제공하여 선택에 도움을 주도록 했습니다.

## 피드백 및 결론

- `SentenceTransformer` 기반으로 기본적인 의미 기반 추천은 가능했습니다.  

- 다만 문장이 길어지거나 조건이 복합적인 경우, 일부 의도가 충분히 반영되지 않는 한계를 확인했습니다.  

- 향후 한국어 특화 임베딩 모델을 적용하고 데이터 규모를 확장한다면 성능 개선이 가능할 것으로 보고 있습니다.

## 사용 방법

1. 크롤링 코드는 참고용으로 제공되며, 필요 시 base_url과 페이지 수를 조정해 사용할 수 있습니다.  
   (웹사이트 구조 변경 시 selector 수정이 필요할 수 있습니다)

2. 저장소 파일을 다운로드한 후 ‘데이터 전처리’부터 ‘추천 시스템’까지 순차적으로 실행합니다.

3. ‘추천 시스템 실행’ 단계에서 모델 다운로드 및 임베딩을 수행한 뒤, 추천 함수를 실행하면 됩니다.

4. 임베딩 데이터는 용량 문제로 포함하지 않았습니다. 최초 생성 후 pickle 파일로 저장해 재사용하는 방식을 권장드립니다.

## 성능 및 결과

- 정성 평가 기준으로, 입력 쿼리와 관련성이 높은 제품이 상위에 배치되는 경향을 확인했습니다.  

- 필터링 적용 여부에 따라 추천 결과의 정확도와 다양성이 달라지는 점을 확인했습니다.
